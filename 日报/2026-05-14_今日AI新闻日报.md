## 今日重点

### 1. Anthropic 推出 Claude for Small Business
Anthropic 把 Claude 直接嵌入 QuickBooks、PayPal、HubSpot、Canva、DocuSign、Google Workspace 和 Microsoft 365，面向小企业的财务、销售、营销、HR 和客服工作流。  
为什么重要：AI 竞争正在从“大模型能力”下沉到“小团队能否直接开箱即用”，这会直接影响中小企业的采纳速度和续费意愿。  
来源：Anthropic，2026-05-13  
链接：https://www.anthropic.com/news/claude-for-small-business

### 2. NVIDIA 推出 Hermes 自我改进型 AI Agent
NVIDIA 发布 Hermes，强调可持续运行、自我优化的 agent 工作流，并把它和 RTX PCs、工作站以及 DGX Spark 绑定起来，推动本地 agent 生态。  
为什么重要：这说明 AI Agent 正从云端演示走向更贴近开发者和高性能 PC 的本地化部署，边缘算力和个人工作站会变得更关键。  
来源：NVIDIA，2026-05-13  
链接：https://blogs.nvidia.com/blog/rtx-ai-garage-hermes-agent-dgx-spark/

### 3. Meta 为 WhatsApp 和 Meta AI App 加上“隐身聊天”
Meta 推出 Incognito Chat，允许用户在 WhatsApp 和 Meta AI App 里进行更私密的对话，消息在受保护环境中处理，且默认不保存。  
为什么重要：AI 助手的下一阶段不只是“更聪明”，还要“更可信”；隐私模式会成为高频敏感场景的重要卖点。  
来源：Meta，2026-05-13  
链接：https://about.fb.com/news/2026/05/incognito-chat-whatsapp-meta-ai/

### 4. Microsoft 把 AI 引入更高强度的安全防御
Microsoft 发布新一代 multi-model agentic security system，称其在 CyberGym 基准上拿到领先成绩，并用于发现 16 个 Windows 漏洞。  
为什么重要：AI 已经从“提高效率”扩展到“自动找漏洞、做防御”，安全领域会继续成为代理式 AI 的高价值落点。  
来源：Microsoft，2026-05-12  
链接：https://www.microsoft.com/en-us/security/blog/2026/05/12/defense-at-ai-speed-microsofts-new-multi-model-agentic-security-system-tops-leading-industry-benchmark/

### 5. Ramp 数据显示 Anthropic 首次领先 OpenAI 的企业付费采用
TechCrunch 引述 Ramp AI Index 指出，Anthropic 的企业付费占比达到 34.4%，首次超过 OpenAI 的 32.3%。  
为什么重要：这反映企业端正在更重视代码、工作流和交付场景，模型竞争的焦点已经延伸到实际使用份额。
